# 🖼️ estaticos-vendedores

Estáticos para **Meta Ads** que venden, no solo que se ven bonitos. Pensado para traffickers, no diseñadores.

- **Info del negocio:** desde el Instagram, la landing o a mano. La landing es la fuente de verdad del copy.
- **Ficha de marca:** paleta, tipografías, logo y tono; se guarda en `marcas/<cliente>/ficha.md` para reutilizarla.
- **3 ángulos de venta** distintos entre sí, con uno recomendado como control.
- **Copy** para la pieza y para el Administrador de Anuncios (texto principal, título, botón).
- **Generación:** Higgsfield (Nano Banana en plan gratis), otro generador, o maquetado HTML → PNG con Chrome headless
  (`scripts/maquetar_html_ejemplo.py`).
- **Control de calidad** con zonas seguras de 9:16 y políticas de Meta, y entrega con tabla de test A/B.

## Requisitos

- Opcional: Higgsfield conectado, `mcp__meta-ads` para investigar a la competencia, Google Chrome para el plan HTML.

## Disparadores

*«hazme estáticos para [cliente]»*, *«creativos para pauta»*, *«artes para ads de WhatsApp»*.
